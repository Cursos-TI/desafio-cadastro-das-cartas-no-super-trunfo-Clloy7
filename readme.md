#Desafio das cartas-Super-Trunfo-Países

// Entrada de dados: 
O programa pede ao usuário que insira os dados de duas cidades, incluindo nome, população, área, PIB e pontos turísticos.

// Cálculos:
 O programa calcula a densidade populacional, PIB per capita e "super poder" para cada cidade.

// Comparação:
 O programa compara os dados das duas cidades e determina qual cidade vence em cada categoria (população, área, PIB, pontos turísticos e super poder).

// Saída:
 O programa imprime os resultados da comparação, mostrando qual cidade venceu em cada categoria.

** Funcionalidades

- O programa usa variáveis para armazenar os dados das cidades e os resultados dos cálculos.
- O programa usa operadores lógicos e aritméticos para realizar os cálculos e comparações.
- O programa imprime os resultados da comparação usando printf.

O programa pede ao usuário que insira os dados de duas cidades, incluindo nome, população, área, PIB e pontos turísticos. Em seguida, o programa calcula a densidade populacional, PIB per capita e "super poder" para cada cidade e compara os resultados, determinando qual cidade vence em cada categoria. Por fim, o programa imprime os resultados da comparação.
